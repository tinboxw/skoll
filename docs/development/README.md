## 维护规则

1. 开发文档只放可执行、可复用的当前流程。
2. 历史计划、阶段报告和一次性验收材料放入 `docs/archive/`。
3. 新增开发文档时，同步更新本文件和 `docs/README.md`。
4. 示例命令必须写明工作目录和预期结果。
