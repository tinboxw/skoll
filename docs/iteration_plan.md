### 1.4 项目注意事项（强制）

> 生效时间：立即生效（项目初始阶段）

1. 当前项目所有系统改造不考虑任何老旧系统、老旧数据结构或兼容层。
2. 首要目标是建立完善、规范、可长期演进的技术基建，不以短期兼容为代价。
3. 数据库层面严格要求：
    - 立即停止新增任何“兼容老旧数据”的临时表与映射表。
    - 彻底删除所有老旧数据及相关老旧表结构。
    - 前后端代码、数据库设计、前端实现全部切换为全新数据结构。
    - 严格执行新的数据规范，不保留回退路径和兼容分支。
4. 用户数据模型强制规范：
    - 用户表采用“账号 + 名称”字段模式。
    - 禁止使用 `displayname` / `display_name` 字段。
