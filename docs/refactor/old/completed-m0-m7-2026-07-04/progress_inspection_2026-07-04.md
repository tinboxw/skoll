- 下一阶段需要新建功能体验候选池，并以 F0-F5 作为开发主线。

方向校准结论:

- 架构方向继续沿用 Modular Monolith + Clean/Hexagonal boundaries + Tactical DDD，普通 CRUD 保持简单可生成。
- 下一阶段主目标是从“基础能力齐全”升级到“功能强、界面好、交互顺、可高频使用”。
- 不做旧兼容和新旧双轨；所有新功能直接面向当前契约、当前 UI 和当前插件/生成器模型。
