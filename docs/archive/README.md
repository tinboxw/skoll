# Skoll 文档归档

本目录保存历史计划、阶段报告和一次性验收材料。归档文档只作为历史证据，不作为当前任务执行入口。

## 目录

| 目录/文件 | 用途 |
| --- | --- |
| [legacy-plans](legacy-plans) | 旧路线图、旧计划和旧设计草案 |
| [refactor-2026-06-19](refactor-2026-06-19) | 2026-06-19 重构批次过程文档、FE0-FE6 细节材料、M2 验收材料和尾盘巡检记录 |
| `*.md` | 早期阶段报告、插件平台计划、质量门禁报告等历史材料 |

## 使用规则

1. 当前执行文档以 `docs/README.md` 和 `docs/refactor/README.md` 为准。
2. 不要从归档目录直接派发新任务。
3. 归档内容若仍有价值，先摘录到当前主文档，再继续保持归档状态。
4. 归档中的旧兼容、旧路径、旧接口方案不作为 Skoll 当前基础建设依据。
