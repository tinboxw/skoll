# 插件能力扩展实施方案（上传/外链/嵌入）

更新时间：2026-05-10
状态：S3 设计基线（可执行）

## 1. 目标

- 补齐插件上传能力。
- 支持外部链接挂载。
- 支持外部页面嵌入与安全降级。

## 2. 三类功能实现

### 2.1 上传插件（Upload）

流程：
1. 上传包到临时区。
2. 校验清单、版本、签名、依赖。
3. 异步安装任务执行（解包、注册、状态回写）。
4. 前端展示任务进度与失败原因。

接口建议：
- POST /v1/plugins/upload
- POST /v1/plugins/install
- GET /v1/plugins/jobs/{jobId}

权限：
- 仅 super_admin 可上传与安装。

安全：
- 文件类型白名单、大小限制、病毒扫描。
- 防路径穿越、防恶意脚本注入。

### 2.2 外挂外部链接（Link）

流程：
1. 新建 Link 类型插件。
2. 配置 URL、图标、菜单位置、打开方式。
3. 按权限下发可见性。

接口建议：
- POST /v1/plugins/link
- PUT /v1/plugins/{pluginId}/link

权限：
- 创建/编辑权限与访问权限分离。

安全：
- 强制 https。
- 域名白名单。
- 新窗口统一 noopener noreferrer。

### 2.3 外挂外部页面（Embed）

流程：
1. 新建 Embed 类型插件。
2. 配置目标 URL、iframe 高度策略、鉴权策略。
3. 无法嵌入时自动降级为新窗口打开。

接口建议：
- POST /v1/plugins/embed
- PUT /v1/plugins/{pluginId}/embed

权限：
- 菜单可见权限 + 页面访问权限双控。

安全：
- iframe sandbox。
- CSP 白名单。
- 跨域 header 兼容检查（X-Frame-Options）。

## 3. 界面设计建议

- 插件列表增加类型标签：builtin/upload/link/embed。
- 新建插件改为向导：选择类型 -> 填写配置 -> 预校验 -> 提交。
- 详情页统一展示：基础信息、路由入口、权限、任务记录、审计记录。

## 4. 优先级与资源

优先级：
1. P0 Link（快速补齐业务入口）
2. P1 Upload（核心能力）
3. P2 Embed（复杂安全场景）

资源估算：
- 前端 1 人
- 后端 2 人
- 安全评审 0.5 人
- 2-4 周

## 5. S3 完成标准

- 三类插件均可创建、编辑、启停。
- 权限校验、审计记录完整。
- 安全策略生效，异常可观测。
